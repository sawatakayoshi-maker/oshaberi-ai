# 🎨 Canva Studio

ブラウザだけで動く、Canva風のデザインツール＋AIプロンプト生成ツールです。
インストール不要・完全ローカルで動作します（外部APIは一切使いません）。

## 🚀 起動方法（Windows 11）

`canva-studio` フォルダ内の **`start.bat`** をダブルクリックするだけ。

- Python が入っていれば自動でローカルサーバー（`http://localhost:8000`）を立ち上げてブラウザを開きます。
- Python が無くても、`index.html` を直接ブラウザで開きます。

> 💡 コピー機能を確実に動かすため、ローカルサーバー（Python）経由での起動を推奨します。
> Python が無い場合は [python.org](https://www.python.org/downloads/) からインストールしてください（インストール時に「Add Python to PATH」にチェック）。

### macOS / Linux / WSL の場合
```bash
cd canva-studio
bash start.sh
```
または `index.html` をブラウザで開くだけでも動作します。

## ✨ 機能

### デザイン機能（左タブ「素材・テキスト」）
- **テキスト追加**：ダブルクリックで編集／フォントサイズ・色・太字・斜体・下線・整列・フォント変更
- **図形追加**：四角・角丸四角・円・楕円・三角・直線・星・ハートをワンクリックで追加、色はカラーピッカーで自由に変更
- **ドラッグ操作**：移動・四隅ドラッグでサイズ変更・回転・`Delete`キーで削除
- **背景変更**：プリセット色／グラデーション／カスタムカラーピッカー
- **キャンバスサイズ**：SNSバナー(1200×630)、Instagram正方形、縦型ストーリー、YouTubeサムネ
- **重ね順・不透明度・元に戻す(Ctrl+Z)・全消去**
- **PNGダウンロード**：2倍解像度の高画質PNGで書き出し

### AIプロンプト生成ツール（左タブ「AIプロンプト」）
- **① 神イラスト・画像生成プロンプトメーカー**
  イメージ／タッチ／雰囲気を選ぶと、DALL·E 3・Gemini・Midjourneyにそのまま貼れる
  品質ブースター付きの詳細な英語プロンプト（呪文）を自動生成。
- **② バズる縦型ショート動画構成プロンプトメーカー**
  テーマ／ターゲット／トーンを入れると、視聴維持率を意識したタイムライン台本を
  AIに書かせるための「役割・前提・出力フォーマット」完備の指示文を自動生成。
- どちらもワンクリックコピー＆トースト通知（「コピーしました！」）付き。

## 🛠 使用技術
- [Tailwind CSS](https://tailwindcss.com/)（CDN）— UIデザイン
- [Fabric.js](http://fabricjs.com/)（CDN）— キャンバス操作・PNG書き出し
- Vanilla JavaScript — 追加ライブラリのビルド不要

## 📁 ファイル構成
```
canva-studio/
├─ index.html   … 画面の構造
├─ style.css    … デザイン（Tailwindに上乗せ）
├─ script.js    … 全機能のロジック
├─ start.bat    … Windows用 起動スクリプト
├─ start.sh     … mac/Linux/WSL用 起動スクリプト
└─ README.md
```
