# サイト更新内容（v6）─ 採用戦略「実行プラン2.1」対応版

採用戦略資料（実行プラン2.1）に合わせたバージョンアップです。
**実費0円**。残る作業は「値の入力」だけです（下記チェックリスト参照）。

## 新機能・改善点

1. **流入元（UTM・参照元）の自動記録** ← NEW
   - SNSに貼った `?utm_source=...` 付きリンクで来訪した人が応募・問い合わせすると、
     送信内容に「流入元」が自動で添付されます。
   - **GA4を設定していなくても**「どのSNS経由の応募か」がメールで分かります。
   - GA4設定済みの場合は、応募イベント（entry_submit / contact_submit）にも流入元を送信します。

2. **案内チャットの募集要項連動** ← NEW
   - 管理画面で募集要項（職種・給与・勤務時間・休日）を入力すると、
     チャットボットの「募集要項・応募方法」の回答にも自動で反映されます。

3. **採用ページの強化（間口を広げる）**
   - ページ冒頭に「未経験OK／資格は入社後に取得支援／履歴書不要・30秒エントリー」のバッジを追加。
   - 「応募から入社まで、4ステップ。」セクションを新設し、応募のハードルを下げました。

4. **管理画面のUTMリンク作成を強化**
   - 媒体ごとの貼り付け場所ガイド付きに（TikTok／Instagram／YouTube／X／チラシ・名刺QR用）。
   - キャンペーン名は config.js の `utmCampaign`（初期値 recruit2026）で統一。

5. **検索対策の小改善**
   - 会社の構造化データ（sameAs）にSNS 4媒体すべてを反映するようにしました。

## v6.1 追加：メンバー紹介ページ（members.html）

- 集合イラストを上部に表示し、**顔をクリックすると下の個別紹介パネルへジャンプ**します
  （マウスを乗せると名前がポップアップ表示）。
- 個別パネルの顔は、集合イラストから**自動で切り出して**表示します（画像は1枚だけでOK）。
- **設置方法**：集合イラストを `assets/crew.png` という名前で置くだけです。
- **名前・役割・ひとことの編集**：members.html 下部の `CREW` リストを書き換えてください
  （現在はサンプルの愛称が入っています）。
- 顔の位置がずれる場合は、CREW の `cx`（横）・`cy`（縦）を 0〜1 の割合で微調整してください。

## v6.2 追加：乗組員の管理画面編集・トップページ反映

- **管理画面に「🚢 乗組員」タブを追加**：メンバー紹介パネルの名前・役割・ひとことを
  画面から追加・編集・削除・並べ替えできます（公開反映は「公開用書き出し」→ crew.js を設置）。
- 顔の位置（cx・cy）が空欄のメンバーは**顔なしパネル（頭文字アバター）**として表示されます。
  集合イラストに描かれていない人もすぐ追加できます。
- **トップページに「06 ／ MEMBERS」セクション**を追加：集合イラストからメンバー紹介ページへ誘導。
- **全ページのヘッダーに「メンバー」リンク**を追加しました。
- 初期データは assets/crew.js に移動しました（members.html と管理画面で共有）。
- assets/crew.png は現在**デモ画像**です。本番の集合イラストを同じファイル名で上書きしてください。
