# サイト更新内容（v6）─ 採用戦略「実行プラン2.1」対応版

採用戦略資料（実行プラン2.1）に合わせたバージョンアップです。
**実費0円**。残る作業は「値の入力」だけです（下記チェックリスト参照）。

## 新機能・改善点

1. **流入元（UTM・参照元）の自動記録** ← NEW
   - SNSに貼った `?utm_source=...` 付きリンクで来訪した人が応募・問い合わせすると、
     送信内容に「流入元」が自動で添付されます。
   - **GA4を設定していなくても**「どのSNS経由の応募か」がメールで分かります。
   - GA4設定済みの場合は、応募イベント（entry_submit / contact_submit）にも流入元を送信します。

2. **案内チャットの募集要項連動** ← NEW
   - 管理画面で募集要項（職種・給与・勤務時間・休日）を入力すると、
     チャットボットの「募集要項・応募方法」の回答にも自動で反映されます。

3. **採用ページの強化（間口を広げる）**
   - ページ冒頭に「未経験OK／資格は入社後に取得支援／履歴書不要・30秒エントリー」のバッジを追加。
   - 「応募から入社まで、4ステップ。」セクションを新設し、応募のハードルを下げました。

4. **管理画面のUTMリンク作成を強化**
   - 媒体ごとの貼り付け場所ガイド付きに（TikTok／Instagram／YouTube／X／チラシ・名刺QR用）。
   - キャンペーン名は config.js の `utmCampaign`（初期値 recruit2026）で統一。

5. **検索対策の小改善**
   - 会社の構造化データ（sameAs）にSNS 4媒体すべてを反映するようにしました。
