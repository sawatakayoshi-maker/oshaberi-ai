# パイプラント サイト 編集ガイド（管理者向け）

専門知識がなくても更新できるよう、**よく変更する項目を1か所に集約**しています。
まずはこのガイドの「1.」だけ覚えればOKです。

---

## 0. いちばん簡単な方法：管理画面 admin.html

ファイルを直接編集しなくても、**ブラウザで `admin.html` を開く**だけで
「会社情報」「お知らせ」「施工事例」を画面から更新できます。

1. `admin.html` を開く → パスコード（初期値 **pipeplant**／`assets/admin.js` で変更可）でログイン
2. タブを選んで編集・保存 → 同じ端末・ブラウザのサイトに即時反映
3. 全員に反映するときは「公開用書き出し」で `config.js` / `news.js` を書き出し、
   サーバーの `assets/` に上書き設置（または制作者に渡す）

詳しい使い方は「解説書＆運用マニュアル」(pptx) を参照してください。
以下は、ファイルを直接編集したい場合の手順です。

---

## 1. 会社情報を変える（電話・住所・メール・SNS など）

**`assets/config.js` だけ**を編集してください。ここを直すと **全ページに自動反映**されます。

```js
window.SITE = {
  companyName : "株式会社パイプラント",
  tel         : "0776-51-9550",   // ← 電話番号
  fax         : "0776-51-9551",   // ← FAX
  postal      : "〒919-0411",
  address     : "福井県坂井市春江町藤鷲塚37-18",
  email       : "",               // ← メール（決まったら入力）
  instagramUrl: "",               // ← InstagramのURL（入力すると自動でリンク有効化）
  mapEmbed    : "",               // ← Googleマップ「埋め込み」のURL（入力すると地図が自動表示）
  formEndpoint: "",               // ← 問い合わせフォームの送信先（下の「4.」参照）
  siteUrl     : "https://www.example.co.jp"  // ← 公開後の正式URL
};
```

- 電話番号は、文中の表示・発信リンク・モバイル下部バーすべてに自動反映されます。
- `email` を入れると、問い合わせフォームの送信先や会社概要のメール欄に使えます。

---

## 2. Googleマップを表示する

1. Googleマップで会社の場所を開く →「共有」→「**地図を埋め込む**」
2. 表示された `<iframe src="...">` の **src の URL部分だけ**をコピー
3. `config.js` の `mapEmbed` に貼り付け
→ 会社概要ページ・お問い合わせページの地図枠に自動で地図が表示されます。

## 3. Instagramを有効化する

`config.js` の `instagramUrl` にアカウントURL（例 `https://www.instagram.com/xxxx/`）を入れると、
会社概要ページの「Instagramをフォロー」ボタンが自動で有効になります。

## 4. お問い合わせフォームを“実際に届く”ようにする

初期状態では、送信ボタンで**メールソフトが開く方式**で動きます（`email` 設定が必要）。
メールで自動受信したい場合は、無料の **Formspree**（formspree.io）等が簡単です。

1. Formspreeで登録し、フォーム用のURL（例 `https://formspree.io/f/xxxx`）を取得
2. `config.js` の `formEndpoint` に貼り付け
→ フォーム送信が、設定したメール宛に届くようになります（サーバー不要）。

---

## 5. 文章・写真を差し替える

- 各ページは `xxxx.html` をテキストエディタで開いて編集します。
- 仮の箇所はオレンジの破線タグ **「後日差し替え」** が目印です。検索して順に埋めてください。
- 写真の仮枠は `class="ph-img"` の部分です。画像に差し替えるには、その `<div class="ph-img">…</div>` を
  `<img src="images/写真.jpg" alt="説明" />` に置き換えます（`images` フォルダを作って画像を入れる）。

## 6. 施工事例を増やす

`works.html` の `<article class="work">…</article>` を1つコピーして貼り付け、
カテゴリ・タイトル・説明・写真を変えるだけで事例が増やせます。

## 6-2. お知らせ（News）を追加する

**`assets/news.js`** の配列の先頭に、`{ }` を1つコピーして増やすだけです。
トップページ（最新3件）と `news.html`（全件）に自動表示されます。

```js
window.NEWS = [
  { date:"2026-06-01", tag:"お知らせ", title:"見出し", body:"本文", link:"" },
  // ↑ これをコピーして上に足していく（新しい順）
];
```
- `link` に `works.html` や `https://...` を入れると、その項目がリンクになります。
- お知らせを定期的に更新すると、検索エンジンの評価（鮮度）が上がり、閲覧増につながります。

## 6-3. アクセス解析（Googleアナリティクス）

訪問数を計測したい場合は、GA4の「測定ID（G-から始まる文字列）」を
`config.js` の `gaId` に入れるだけで計測が始まります（コード追記は不要）。

## 7. メニュー項目を変える

各HTMLの `<nav class="nav-links">` とフッターの `<nav class="ft-links">` のリンクを編集します。
※全ページ共通なので、同じ変更を各ページに行ってください。

---

## 8. 公開時にやること（SEO）

1. `config.js` の `siteUrl` を正式URLに変更
2. `robots.txt` と `sitemap.xml` の中の `https://www.example.co.jp` を正式URLに置換
3. Google Search Console に `sitemap.xml` を登録
4. Googleビジネスプロフィール（無料）に会社を登録すると、地図検索に強くなります

---

## ファイル構成

```
pipeplant/
├─ index.html        トップ
├─ about.html        私たちについて
├─ business.html     事業内容
├─ works.html        施工事例
├─ hydrogen.html     水素への挑戦
├─ clients.html      発注をお考えの方へ
├─ recruit.html      採用情報
├─ company.html      会社概要
├─ contact.html      お問い合わせ
├─ sitemap.xml / robots.txt   SEO用
└─ assets/
   ├─ config.js   ★会社情報（ここを編集）
   ├─ style.css   デザイン（共通）
   └─ site.js     共通の動き（ナビ・チャット・フォーム等）
```
