# フェーズ0 受け入れ確認手順

> 目的: 実機で A4 を 5 ページ連続スキャンし、PDF 1 本が保存され、一覧から再表示できること（失敗 0/5）。

## 前提

- 実機（Android 実機 / iPhone 実機）で実行していること。エミュレータ・シミュレータはカメラ不可。
- `./tool/bootstrap.sh` 実行済み、README の「プラットフォーム設定」を適用済み。

## 手順

1. アプリを起動する（初回は一覧が空で「まだ書類がありません」と表示される）。
2. 右下「スキャン」をタップ。ネイティブのスキャナ UI が起動する。
3. A4 用紙を **5 ページ連続** で撮影する。
   - 各ページで四隅が自動検出され、台形補正されることを確認する。
4. スキャナ UI を確定（保存）する。
5. 「保存しました（5ページ）」のスナックバーが出て、一覧に 1 件追加されることを確認する。
6. 一覧の項目に「5ページ ・ 日時」が表示されることを確認する。
7. 項目をタップし、PDF が **5 ページ分** アプリ内ビューアで再表示できることを確認する。
8. アプリを完全終了 → 再起動し、一覧に同じ項目が残っている（端末内に永続化されている）ことを確認する。

## 合否判定

| 判定項目 | 基準 |
| --- | --- |
| 連続スキャン | A4 5 ページを 1 セッションで撮影できる |
| PDF 保存 | 1 本の PDF として保存される（ページ数 = 5） |
| 一覧表示 | 保存後、一覧に 1 件表示される |
| 再表示 | 一覧タップで全 5 ページを再表示できる |
| 永続化 | 再起動後も一覧に残る |
| 失敗回数 | 上記を通して失敗 0 / 5 |

すべて満たせばフェーズ0 完了。
