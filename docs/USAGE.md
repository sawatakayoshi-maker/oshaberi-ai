# パーソナル ブレイン — 使い方ガイド

あなた専用の「第二の脳」。メモ・タスク・アイデア・知識・人生ログを一元管理し、
**お話（相談相手）／モデル選択／レポート生成**まで統合したアプリです。

基本の流れは **①入れる → ②AIが仕分け → ③育てる → ④引き出す**。
画面上部の入力バーと左サイドバーから、すべての機能にアクセスできます。

> まず動かすには Supabase 接続と API キー設定が必要です（`SETUP.md` 参照）。

---

## まず最初に ― Quick Capture（全画面共通）

画面上部のバー、またはどこでも **`⌘K`（Mac）/ `Ctrl+K`（Windows）** で即入力。

- 例:「水素事業について補助金を調べる」→ Enter
- **AIが自動で種別を判定**して保存します（タスク／アイデア／メモ／ログ）
- タイトル・タグ・優先度・期限も自動推定

> 迷わず「とりあえず入れる」。仕分けはあとで直せます。

---

## 各機能の使い方（左サイドバー）

### ◎ ダッシュボード（`/`）
今日のタスク・最近のメモ・注目アイデア・通知を一覧表示。1日の起点に。

### ↘ インボックス（`/inbox`）
取り込んだ項目の一覧。AIの判定が違えばプルダウンで**種別変更**、不要なら削除。

### ✎ メモ（`/memos`）
作成・**全文検索**・各メモの **「AI要約」**。

### ☑ タスク（`/tasks`）
期限・優先度つきで追加。**○ をクリックで完了**。期限切れは赤字。

### ✦ アイデア（`/ideas`）
**「AIスコアリング」**で 市場性・実現性・収益性・将来性 を100点採点。高得点順に並びます。

### ▤ プロジェクト（`/projects`）
プロジェクト作成 → 詳細で関連項目を横断表示・追加。

### ⌥ メモリーツリー（`/tree`）
知識を階層管理。**ドラッグ＆ドロップで移動**、ホバーで ＋子追加／改名／削除。

### ⌗ ナレッジグラフ（`/graph`）
項目同士を関連付け → ネットワーク図で自動可視化。ノードはドラッグ可。

### ↗ タイムライン（`/timeline`）
日付＋出来事を記録 → 年ごとに時系列表示（人生ログ）。

### ✺ AI秘書（`/assistant`）
自然言語で質問（例「水素関連で止まっている案件は？」）→ **AI回答＋根拠リンク**。

---

## ★ 新機能

### 💬 お話（`/talk`）― 相談相手・音声対応
- 気軽に話せる**聞き役**のAIと会話。テキストでも音声でも。
- **🎙 マイク**ボタンで音声入力（ブラウザの音声認識）。
- **🔊 声オン**で返答を読み上げ（端末の音声、追加課金なし）。
- **⚙️ 声設定**で VOICEVOX を有効化すると高品質な声に（パソコンで VOICEVOX を起動している場合のみ。未起動時は自動で端末の声）。
- 「会話をクリア」でリセット。
- ※会話は毎回履歴を送るため、長くなるとAI利用料が増えます。

### ▦ レポート生成（`/report`）
整理した内容から、AIがレポート（Markdown）を作成します。
1. **素材を選ぶ**（メモ・アイデア等にチェック）
2. **指示を書く**→「プロンプトを組み立てる」
3. **送信前にプロンプトを確認・編集**（コスト把握のため重要）
4. **「レポート生成」**→ 結果を **メモとして保存** または **.md ダウンロード**

### ⚙️ モデル選択（設定 `/settings`）
- 使用するAIモデルを **Sonnet 4.6（高速・低コスト）/ Opus 4.8（高精度）** から選択。
- 選択は保存され、**全機能（Quick Capture・要約・スコア・お話・レポート等）に反映**。
- 既定は Sonnet 4.6。

### 設定（`/settings`）その他
アカウント確認・**ログアウト**・使用プロバイダの確認。

## 自動でやってくれること
- **通知**: 期限切れタスク／30日以上放置のアイデアを毎日検出（Vercel Cron）。
- **知識進化**: 長く触れていない重要メモ/アイデアを「掘り起こし候補」として記録。

---

## おすすめの1日の流れ
1. 朝: ダッシュボードで今日のタスクと通知を確認
2. 日中: 思いついたら **`⌘K` で即入力**（仕分けはAI任せ）／ moyamoya は **お話** で整理
3. 夜: `/inbox` で微調整、良いアイデアは「AIスコアリング」、知識は `/tree`・`/graph` で関連付け
4. 節目: `/report` で素材を選んでレポート化、`/assistant` で過去の自分に質問

## 困ったとき（抜粋）
| 症状 | 対処 |
|---|---|
| ログイン後にデータが出ない/保存できない | スキーマSQL未適用。`supabase/migrations/0001_init.sql` を実行 |
| Quick Capture が必ず「メモ」になる | `ANTHROPIC_API_KEY` 未設定 or 残高切れ（AI失敗時はメモにフォールバック） |
| お話で声が出ない | 🔊声オンを確認。VOICEVOX 有効時は未起動なら端末の声に切替（iPhone等は端末の声） |
| 音声入力が使えない | ブラウザが Web Speech API 非対応（Chrome 等で再試行） |

詳しい導入・デプロイは `SETUP.md`、設計は `docs/DESIGN.md` を参照してください。
