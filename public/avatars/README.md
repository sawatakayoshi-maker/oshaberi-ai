# アバター画像の差し替えガイド

お話（`/talk`）のアバターは 3 方式に対応しています。実装は `src/lib/avatars.ts`（定義）と
`src/components/avatar.tsx`（表示）です。実写・イラストに差し替える手順は以下のとおり。

状態は `idle`（待機）/ `speaking`（発話・口パク）/ `thinking`（考え中）の3つです。

## ① 1キャラ=1枚の静止画（kind: "image"）
最も簡単。`public/avatars/` に画像を置き、`src/lib/avatars.ts` に追加します。

```ts
{ id: "me", name: "わたし", desc: "マイ写真", kind: "image",
  idle: "/avatars/me.png",
  speaking: "/avatars/me-talk.png",  // 任意（無ければ idle を使用）
  thinking: "/avatars/me-think.png"  // 任意
}
```
- 正方形（例 512×512）推奨。丸く切り抜いて表示されます。
- `speaking` / `thinking` を省略すると常に `idle` を表示します（静止画として動作）。

## ② スプライトシート（kind: "sprite"）
1 枚の画像を格子（cols×rows）に分割し、状態でコマを切り替えます。
今回いただいた「正面・連番（6×2＝12コマ）」シートはこの方式に最適です。

```ts
{ id: "man", name: "男性", desc: "連番シート", kind: "sprite",
  sheet: "/avatars/man.png",
  cols: 6, rows: 2,        // 6列×2行 = 12コマ
  idle: 0,                 // コマ番号は左上から右へ 0,1,2,...（下段は 6,7,...）
  speaking: [4, 5],        // 「口を閉じた笑い/開いた笑い」を交互に
  thinking: 7              // 「考える」
}
```
コマ番号の対応（いただいた 6×2 シートの例）:
`0:ニュートラル 1:微笑み 2:やさしい笑顔 3:明るい笑顔 4:笑顔(口閉) 5:笑顔(口開)`
`6:真剣 7:考える 8:うなずき 9:OKサイン 10:指差し 11:ガッツポーズ`

- セルが均等割りであることが前提です（背景位置で切り出すため）。
- 余白やキャプションが各コマに入っていると顔がずれます。必要なら均等な顔だけのシートに整えてください。

## 補足
- 同梱の `mentor.svg`（静止画の例）/ `sprite-4.svg`（2×2 スプライトの例）はデモ用です。
- 内蔵の SVG アバター（`kind: "svg"`）は画像不要で表情アニメします（既定の AI / みなと / あすか）。
